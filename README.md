# WordVel Bridge

WordVel Bridge is the frontend-side preview sync library for WordVel.

It lets an SPA project render its real components with WordVel placeholder values, collect the CSS used by the app, and send that preview artifact to a WordVel Laravel API endpoint. WordPress then uses that artifact to make custom Gutenberg blocks look close to the real website while editors work with content.

The first proof supports React, but the package name is intentionally generic so Vue, Svelte, Solid, and other SPA adapters can grow from the same bridge idea.

## What It Does

- Reads the WordVel manifest generated by the Laravel API project.
- Renders registered frontend components with placeholder values matching DTO field names.
- Collects linked stylesheets and configured CSS files.
- Posts block preview HTML and CSS to the WordVel editor preview endpoint.

## Usage

Create a config file in the SPA project:

```js
import { Hero } from "./src/components/Hero.jsx";
import { FeatureGrid } from "./src/components/FeatureGrid.jsx";

export default {
  manifest: "../wordvel/testing/laravel/storage/wordvel/manifest.json",
  endpoint: "http://wordvel-api.test/api/wordvel/editor-preview",
  document: "./dist/index.html",
  css: ["./dist/assets/app.css"],
  blocks: {
    hero: Hero,
    feature_grid: FeatureGrid,
  },
};
```

Then sync previews:

```bash
npx wordvel-bridge sync wordvel.config.mjs
```

The legacy proof command also remains available for now:

```bash
npx wordvel-react sync wordvel.config.mjs
```

## Current Status

This is an early proof library. The API is expected to change as WordVel's editor preview, asset transfer, and framework adapter story become clearer.
